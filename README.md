# Road-Accident-Analysis
Interactive dashboard showcasing road accident casualty insights by type, vehicle, location, and road conditions using dynamic visuals
## Road_ Accident_Report
This Report provides key insights showing that most road accident casualties are slight, occur in urban areas, and predominantly involve cars on dry roads.
## Project Overview
>+ This report presents an interactive Power BI dashboard that analyzes road accident data to uncover trends in casualty severity, vehicle types involved, road conditions, and geographical distribution. The dashboard enables stakeholders to quickly identify high-risk areas, understand contributing factors, and support data-driven decisions for improving road safety. Visual elements include bar charts, KPIs, and filters for dynamic exploration of accident patterns across different scenarios
## Importance of the project
In this project, I focused on visualizing and analyzing road accident data to uncover key insights about casualty trends, contributing factors, and high-risk conditions. I followed the tutorial by Swapnjeet S, adapting the process to build an interactive and insightful dashboard using Power BI.
